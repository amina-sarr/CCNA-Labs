# CCNA-Labs

Laboratoires et fiches de révision réalisés dans le cadre de ma préparation à la
certification **Cisco CCNA 200-301 v2.0**.

## 📂 Contenu du dépôt

| Fichier | Description |
|---|---|
| [`01-lab-synthese.md`](01-lab-synthese.md) | Lab complet reliant les 5 domaines : OSPF, route par défaut, NAT/PAT, VLAN, trunk, inter-VLAN, STP, port-security, DHCP, DNS, NTP. |
| [`02-depannage.md`](02-depannage.md) | Fiche de dépannage : 5 pannes types (symptôme → cause → commande → réflexe). |

## 🛠️ Outils

- **GNS3** — partie routage (OSPF, NAT)
- **Cisco Packet Tracer** — commutation et services
- **Cisco IOS** — configuration en ligne de commande

## 📘 Domaines CCNA couverts

1. **Fondamentaux réseau** — adressage IPv4/IPv6, VLSM, interfaces
2. **Accès réseau** — VLAN, trunk 802.1Q, STP, EtherChannel
3. **Connectivité IP** — routage statique, OSPF, NAT/PAT
4. **Sécurité** — port-security, DHCP snooping, SSH, AAA
5. **Automatisation & services** — DHCP, DNS, NTP, SNMP, syslog
